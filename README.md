# React Pricing Cards

A responsive pricing plans UI built using React and CSS. 
This project demonstrates reusable components, props, 
dynamic rendering, and conditional styling.

## Features

- Three pricing plans: Free, Plus, and Pro
- Reusable PricingCard component
- Dynamic rendering using the map() method
- Props for passing pricing plan data
- Conditional rendering of available and unavailable features
- Tick and cross icons for feature availability
- Hover effects and smooth CSS transitions
- Responsive layout for different screen sizes

## Tech Stack

- React
- JavaScript
- HTML5
- CSS3
